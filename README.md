# State-Space Trajectory

**John Brajer — Choseverse decision architecture**  
Public version: 0.1.

## Core transformation

```
Current State
    ↓
Action
    ↓
Weight Shift
    ↓
New State
    ↓
New Possibilities
```

The future cannot be controlled directly, but actions can alter the distribution of reachable future states.

The decision question is therefore:

> Given where you are right now, which available action changes your trajectory the most?

## Example state variables

- time
- money
- energy
- location
- information
- confidence
- network access
- visibility
- current commitments
- creative momentum

## Action dimensions

Candidate actions can be evaluated across dimensions such as:

- money
- network
- visibility
- risk
- confidence
- future options
- reversibility
- information gain
- alignment
- path expansion

## Path Expansion

A particularly important variable is how many desirable future states an action makes reachable.

An action with a modest immediate payoff can still be high-value if it substantially expands future option space.

## Learning loop

Predicted effects and actual effects can be compared over time so a system updates the user's personal weighting model rather than assuming universal static weights.
